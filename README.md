# Kuidao

Software for home care, nurse registry, and home health agencies staffing their own cases, and for caregivers finding shifts. Caregivers join free. Agencies pay a monthly plan. The product starts in Florida and is built to expand nationwide.

The site opens with a two-door chooser. Agency marketing, including pricing, lives on its own page. Caregiver pages do not show plans or prices.

Private repo. Accounts, payments, and a live map are not wired yet. Search and signup are demos.

Agency marketing on `/for-agencies` and `/pricing` adapts section structure from the free [Mainline Next.js template](https://github.com/shadcnblocks/mainline-nextjs-template) (shadcnblocks, MIT plus Commons Clause). Those blocks are restyled to the Verce theme and rewritten for Kuidao. See `src/components/mainline/NOTICE.md`.

## Cursor

1. In Cursor, clone `https://github.com/romaniantwinkie/kuida` (or File → Open Folder after you clone it).
2. Install Node LTS from https://nodejs.org if you do not have it.
3. In the terminal:

```bash
npm install
npm run dev
```

4. Open http://localhost:3000
