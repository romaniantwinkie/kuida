# Kuida

Private repo for the caregiver staffing site.

## Cursor

1. In Cursor, clone `https://github.com/romaniantwinkie/kuida` (or File → Open Folder after you clone it).
2. Install Node LTS from https://nodejs.org if you do not have it.
3. In the terminal:

```bash
npm install
npm run dev
```

4. Open http://localhost:3000

Accounts, payments, and a live map are not wired yet. Search and signup are demos.
