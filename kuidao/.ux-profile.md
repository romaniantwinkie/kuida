# Cercana UX profile

Decisions the VectorLab UX skills (and anyone editing this app) should follow.

## Aesthetic
- **Archetype:** utilitarian, healthcare-calm (Stripe-like restraint).
- **Colour:** Slate neutrals + **one blue accent** (`--brand` #1D4ED8 light / #8AB4FF dark) for actions, links, focus and selection.
  Status colours (ok / warn / danger / info) are reserved for state, never decoration. Target 60-30-10 (canvas / surfaces / accent).
- **Type:** Inter only, weights **400 / 500 / 600** (never 700). Sizes: 12 / 14 / 16 / 20 / 24 / 32 / 48. Nothing below 12px.
  Accessibility option in the caregiver app: Atkinson Hyperlegible.
- **Elevation:** 1px border first, then soft shadow (alpha < 0.08). Dark mode uses an inset top highlight, never glow.
- **Spacing:** 8pt for layout, 4pt for micro-spacing. Prose max ~65ch.

## Accessibility
- WCAG 2.1 **AA**. Hit targets **44 × 44px**. Visible focus ring on every control (2px accent outline, 2px offset).
- Honour `prefers-reduced-motion` (instant changes; hero demo shows its final state).
- Overlays trap focus and restore it to the trigger; Esc closes.

## Voice
- Plain, direct, verb-first buttons ("Send message", "Rank caregivers"). Sentence case. Never "OK / Submit / Proceed".
- Errors never blame the user and always say how to recover.
- Agency side: English. Caregiver side: English and Spanish (toggle), never both on one line.
- Say "roster", not "bench". Don't claim results we can't show (label examples as examples).

## Motion
- 150ms / 200ms / 300ms, ease-out on enter. Only `transform` and `opacity`. No infinite decorative loops.

## Banned
- Glassmorphism / `backdrop-filter`, decorative gradients, glows and dot grids.
- Pastel pills on static metadata (pills = status or filters only).
- Cartoon people in empty states (profile avatars are fine).
- Disabled submit buttons as the only feedback. Native `title` as a tooltip.
- Data export options (product decision).
